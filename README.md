# Embedded Motor Control Lab

A Python project demonstrating embedded systems and control engineering concepts through DC motor simulation.

## Current Modules

- ✅ DC Motor Speed Simulation
- ✅ PWM Motor Control Simulation
- ✅ Encoder Simulation
- ✅ PID Speed Controller

## Technologies

- Python
- NumPy
- Matplotlib

## How to Run

```bash
python dc_motor_simulation.py
python pwm_control.py
python encoder_simulation.py
python pid_speed_controller.py

## Future Development

- PWM Motor Control
- Encoder Simulation
- PID Speed Controller
- Step Response Analysis
- Closed-Loop Control
- Interactive Motor Dashboard
```
